# NEXUS SHIFTER — متحوّل النيكسوس

لعبة عدّاء لانهائي ثلاثية الأبعاد بجرافيك عالي (Three.js / WebGL) مع بطل فضائي يتحوّل بين ثلاثة أشكال، وخمسة بيئات مختلفة، ودعم كامل للعربية والإنجليزية.

## الفكرة المبتكرة

ليست لعبة قفز وتفادٍ فقط:

1. **المتحوّل الكوني**: جسم الفضائي يتحوّل لحظياً بين:
   - **بلازما** 🔥 — يعبر نيران الحمم ويهضمها.
   - **كريستال** 🔵 — يكسر العقبات الصلبة البلورية.
   - **ظل** 🟣 — يمر عبر العقبات الظلية الغامضة.

2. **عقبات تفاعلية ذكية**: كل عقبة ترتبط بالشكل الصحيح، لذا اللاعب يخطط ويغيّر جسده حتى لا يخسر الزخم.

3. **جاذبية مدارية**: في بعض البيئات تظهر "نبضة جاذبية" تزيد أو تخفف حدة القفز وتؤثر على الكاميرا (بفعل ثقب أسود قريب).

4. **مكافأة القرب (Near-Miss)**: المرور بجانب عقبة دون لمسها يرفع سلسلة النقاط.

5. **شظايا DNA**: جمع قطع بيولوجية لتطوير الحمض النووي — لمسة تطورية بدل مجرد عملات.

## التحكم

- `◀` / `▶` — الانتقال بين الممرات
- `Space` أو `W` / `↑` — القفز
- `S` / `↓` — الانزلاق
- `1` / `2` / `3` — تبديل الشكل (بلازما / كريستال / ظل)
- على الجوال: اسحب يميناً/يساراً للتنقل، اسحب للأعلى للقفز، وللأسفل للانزلاق، واضغط أزرار الشكل في الأسفل.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:5173`.

## نشر مباشر عبر GitHub Pages

مجلد `docs/` جاهز للنشر على GitHUb Pages:

1. اذهب إلى إعدادات المستودع:
   `https://github.com/apoadam1209-beep/-/settings/pages`

2. تحت **Build and deployment → Source** اختر:
   `Deploy from a branch`

3. اختر الفرع: `arena/01a068a7-repo` ‏(بدلاً من الفرع الآخر الظاهر حالياً)

4. اختر المجلد: `/docs`

5. اضغط **Save**.

بعد عدة ثوانٍ، اللعبة تكون متاحة على:

```
https://apoadam1209-beep.github.io/-/
```

عند تحديث الكود، أعد البناء والرفع:

```bash
npm run build   # ينشئ مجلد docs/ جاهزاً للنشر
git add docs
git commit -m "build: publish game to docs"
git push origin arena/01a068a7-repo
```
