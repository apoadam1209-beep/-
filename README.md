# صندوقُ الأسرار — ألغاز الحكمة ✦

> لعبة ألغاز عربية مبتكرة: صندوقٌ أسطوري بحلقاتٍ دوّارة من الخط العربي، تُدوَّر بالسحب الحرّ حتى تصطفّ الحروف على شعاع القمر وتكشف جواب اللغز.

![المراحل](https://img.shields.io/badge/المراحل-٢٠-d4af37) ![الألغاز](https://img.shields.io/badge/الألغاز-٢٠٠-2e2364) ![PWA](https://img.shields.io/badge/PWA-قابلة_للتثبيت-171136) ![اللغة](https://img.shields.io/badge/اللغة-العربية-b08d26)

## المميزات

- **٢٠ مرحلة × ١٠ ألغاز = ٢٠٠ لغز** عربي أصيل بموضوعات متنوعة (الحيوان، الفضاء، البحر، الموسيقى، الألوان...)
- **آلية لعب فريدة**: حلقات متحدة المركز تدور بالسحب مع فيزياء قصور ذاتي وطقطقات ميكانيكية، وشعاع قمر ينقش الحرف المصطفّ
- **موسيقى عود تُصنَّع لحظياً** داخل المتصفح بخوارزمية Karplus-Strong على مقام الحجاز — بلا أي ملفات صوتية
- **PWA كاملة**: تُثبَّت على الهاتف وتعمل بلا إنترنت
- رسومات SVG متقنة، خطوط عربية (أميري + رقعة + تجوال)، حفظ تلقائي للتقدم، نظام تلميحات ونجوم

## التقنيات

React 19 · TypeScript · Vite · Tailwind CSS 4 · Framer Motion · Web Audio API · Lucide Icons

## التشغيل والبناء

```bash
# تثبيت الاعتماديات
npm install

# وضع التطوير
npm run dev

# بناء النسخة النهائية → مجلد dist (ملف index.html واحد + أصول PWA)
npm run build

# معاينة النسخة النهائية محلياً
npm run preview
```

## هيكل المشروع

```
src/
├── data/riddles.ts      # ٢٠٠ لغز في ٢٠ مرحلة
├── audio/engine.ts      # محرك الصوت (عود مُصنَّع، مقام الحجاز، مؤثرات)
├── components/
│   ├── PuzzleBox.tsx    # قلب اللعبة: الحلقات الدوّارة والسحب الحر
│   ├── GameScreen.tsx   # شاشة اللعب وتسلسل ألغاز المرحلة
│   ├── Menu.tsx         # القائمة وخُتوم المراحل العشرين
│   ├── WinOverlay.tsx   # ملخص المرحلة والنجوم
│   ├── Confetti.tsx     # قصاصات الاحتفال الذهبية
│   └── Backdrop.tsx     # الزخارف والجمرات الخلفية
└── App.tsx              # إدارة الشاشات والتقدّم المحفوظ
```
