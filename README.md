# XENO RUN 👽 — Alien Endless Runner

لعبة عداء لا نهائية ثلاثية الأبعاد بمنظور خلفي (Third-Person)، بطلها كائن فضائي مُفصَّل، تعمل باللمس داخل متصفح الهاتف مباشرة — بدون تحميل ولا متجر تطبيقات.

> واجهة اللعبة ونصوصها بالإنجليزية بالكامل كما طُلب. هذا الملف هو دليل التشغيل بالعربية.

---

## 🎮 كيف تجرب اللعبة (أسهل طريقة)

**من هاتفك:** افتح رابط المعاينة (Preview) الذي يظهر في Arena، والعب فوراً. لا تحتاج لتثبيت أي شيء.

**اجعلها كتطبيق على شاشة الهاتف (اختياري):**
- iPhone: افتح الرابط في Safari ← زر المشاركة ← *Add to Home Screen*
- Android: افتح الرابط في Chrome ← القائمة ⋮ ← *Add to Home screen / Install app*

سيظهر أيقونة اللعبة على الشاشة الرئيسية وتفتح بملء الشاشة مثل أي تطبيق.

**تشغيلها على جهازك لاحقاً (كمبيوتر):**
```bash
npm install
npm run dev      # وضع التطوير
# أو
npm run build && npm run preview   # النسخة النهائية
```
ثم افتح الرابط الظاهر في الطرفية. لتجربتها على الجوال عبر نفس شبكة الواي فاي، افتح `http://<IP-الكمبيوتر>:4173`.

## ✨ الأفكار المبتكرة (غير موجودة في الألعاب المشابهة)

1. **Phase Shift — بُعدان في نفس المسار**
   الكائن يعيش في طورين لونيين. الجدران الطاقية لا تُتجاوز إلا إذا كان طورك مطابقاً للونها. تصبح اللعبة سباق ذهني بجانب سرعة رد الفعل، وليست مجرد تفادي.

2. **Gravity Inversion Corridors — ممرات قلب الجاذبية**
   بوابات بنفسجية تقلب الجاذبية فتسقط للأعلى وتركض على السقف، مع دوران الكاميرا 180° وانعكاس منطق التحكم ليبقى متوافقاً مع ما تراه.

3. **Titan Overdrive — الوضع العملاق**
   امتلاء شريط الطاقة يمنحك تحوّلاً يحطّم العوائق بدل تفاديها، مع تسارع وموجة صدمية وضوء متوهج.

4. **Close Call + Time Dilation — مكافأة المرور بالكاد**
   المرور على بعد سنتيمترات من عائق يمنحك نقاطاً، شحن طاقة، ونبضة تصوير بطيء. اللعبة تكافئ الجرأة لا الحذر فقط.

5. **THE REAPER — المُطارِد الحي**
   طائرة صيد آلية تحوم فوق كتفك. كل اصطدام يقرّبها منك، وكل ثانية نظيفة تُبعدها. إن أمسكت بك انتهى الشوط حتى لو كانت طاقتك كاملة — توتر مستمر بدل «حياة أو موت» جاف.

6. **Mutation Deck — طفرات دائمة (نظام Roguelite)**
   بعد كل عالم تختار طفرة من ثلاث بطاقات (قفزة مزدوجة، مغناطيس حيوي، درع، تخفيف المطارد، بلازما كثيفة…). كل شوط يصبح بناءً مختلفاً للشخصية.

7. **عالم ينبض مع الموسيقى**
   الموسيقى مُولَّدة برمجياً وتتغير مع كل بيئة وتتسارع مع سرعتك، وأضواء المسار تنبض على الإيقاع.

8. **مولّد مراحل ذكي**
   الأنماط تُبنى إجرائياً مع ضمان وجود مسار نجاة دائماً، وتتباعد الصفوف تلقائياً كلما زادت السرعة لتبقى اللعبة صعبة وعادلة.

## 🌍 البيئات الخمس

| # | البيئة | الطابع |
|---|---|---|
| 1 | **CRYSTAL CANYON** | وديان بلورية متوهّجة، شظايا طائرة، سماء بنفسجية ونجوم |
| 2 | **NEON METROPOLIS** | مدينة سايبربانك ممطرة، لافتات نيون، أبراج ومسار معدني عاكس |
| 3 | **SPORE JUNGLE** | غابة فطرية عملاقة مضيئة، أبواغ طائرة، أرضية طحلبية |
| 4 | **MAGMA FORGE** | مصنع بركاني، برك حِمَم، جمر متطاير وأنابيب صناعية |
| 5 | **AURORA GLACIER** | حقول جليد شفافة، أقواس متجمدة، ثلج متساقط وشفق قطبي |

كل بيئة لها: خامة أرضية مولّدة إجرائياً بدقة عالية + خريطة نتوءات (Normal Map)، ضباب وإضاءة وسماء وأفق خاص، مجسمات جانبية، جزيئات جوّية، ومقام موسيقي مختلف. الانتقال بينها يتم عبر بوابة Warp.

## 🧬 الشخصية

كائن فضائي مبني بالكامل برمجياً (بدون ملفات خارجية) من أكثر من 40 قطعة هندسية مع هيكل عظمي متحرك:
جمجمة ممدودة وعُرف، عينان مركّبتان بقزحية متوهجة، فكّ وصفائح، قرنا استشعار متحركان، نواة صدر تتوهج بلون الطور، زعانف ظهرية تتفتح مع السرعة، ذراعان بثلاثة أصابع، أرجل رقمية (Digitigrade) بمخالب، وذيل من ست فقرات يتموّج أثناء الجري — مع دورة جري وقفز وانزلاق وأنيميشن ثانوي للقرون والذيل.

---

## ⚙️ الأداء والجودة

- ثلاث درجات جودة (LOW / MED / HIGH) + **تخفيض تلقائي** إن انخفض معدل الإطارات تحت 38 لقطة/ث.
- Bloom وToneMapping سينمائي، ظلال ديناميكية في الوضع العالي.
- تدوير كامل للكائنات (Object Pooling) — لا توجد مسحات ذاكرة أثناء اللعب.
- كل الخامات والأصوات مُولَّدة وقت التشغيل: حجم اللعبة صغير وتعمل بلا إنترنت بعد أول فتح.
- دعم شاشات الآيفون ذات النتوء (Safe Area)، الوضع الأفقي والعمودي، ووضع اليد اليسرى في الإعدادات.
