# يلا فاكهة

اسحب الفاكهة لأي اتجاه وطابق ثلاثة. كل دور طلب مختلف: عصير نوع، نوعين، أو سلطة. أحيانًا في تلج.

- ٣٠ قائمة × ١٠ طلبات
- ١٠ فواكه: فراولة، كيوي، مانجو، توت، عنب، برتقال، بطيخ، موز، خوخ، أناناس
- ٤ = عصير يلوّن الصف والعمود ثم ينفجر
- ٥ = طيف يمسح النوع بعد التبديل
- صعوبة: سهل · وسط · صعب (كل ما زادت الأنواع أصعب)

```bash
npm install
npm run build
node server.mjs
```
