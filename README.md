# Creativo — منصة المنتجات الرقمية

منصة عربية (RTL) لبيع المنتجات الرقمية بنظام الاشتراكات الشهرية والسنوية، مبنية بـ
**React + Vite + TypeScript + Tailwind CSS v4**.

## المميزات

- **15 قسماً** للمنتجات الرقمية (قوالب، خطوط، صور، فيديو، موسيقى، مؤثرات صوتية،
  أيقونات، رسوم، عروض تقديمية، قوالب مواقع، كتب، دورات، واجهات UI، شعارات،
  منتجات قابلة للطباعة).
- **75 منتجاً رقمياً** موزعة على الأقسام (5 منتجات لكل قسم، بينها منتج مجاني).
- **نظام اشتراكات**: 4 خطط (مجاني، برو، ستوديو، أجنسري) مع تبديل الفوترة
  الشهرية/السنوية (السنوية = شهران مجاناً).
- **صفحة دفع تجريبية** كاملة (بيانات البطاقة لا تُرسل لأي خادم) مع تأكيد الاشتراك.
- **تحميل المنتجات**: المنتجات المجانية + 3 تحميلات مدفوعة شهرياً للخطة المجانية،
  وتحميل غير محدود للمشتركين. كل تحميل يولّد ملف SVG تعريفي بالمنتج.
- **لوحة تحكم المشترك**: الخطة الحالية، تاريخ التجديد، الاستخدام الشهري،
  سجل التحميلات مع إعادة التحميل، المفضلة، وإلغاء الاشتراك.
- تصفح وبحث وفلترة (القسم، المجاني فقط) وترتيب (الأكثر تحميلاً، الأعلى تقييماً، السعر).
- كل البيانات (الحساب، الاشتراك، التحميلات، المفضلة) محفوظة محلياً في المتصفح.

## التشغيل

```bash
npm install
npm run dev      # بيئة التطوير
npm run build    # بناء الإنتاج (مع فحص TypeScript)
```

## النشر على GitHub Pages

الموقع مبني للنشر من مجلد `docs/` على فرع الجلسة (اسم المستودع `-`، لذا مسار
الأساس `/-/`). أعد البناء ونشره بأمر:

```bash
npm run build:github
git add docs && git commit -m "تحديث نسخة GitHub Pages" && git push
```

ثم من المستودع على GitHub: **Settings ← Pages ← Source: Deploy from a branch**،
اختر الفرع `arena/01a0555b-repo` والمجلد `/docs`، واحفظ. سيكون الرابط:

**https://apoadam1209-beep.github.io/-/**

(ملف `404.html` يضمن عمل الروابط الداخلية للتصفح، و`.nojekyll` يمنع معالجة Jekyll.)

## البنية

```
src/
├── data/          # الأقسام، المنتجات (75)، خطط الاشتراك
├── context/       # AppContext: المستخدم والاشتراك والتحميلات
├── components/    # Navbar, Footer, ProductCard, CategoryCard, AuthModal...
├── pages/         # Home, Browse, Categories, CategoryPage, ProductPage,
│                  # Pricing, Checkout, Dashboard, NotFound
└── utils/         # تنسيق الأرقام/التواريخ وتوليد ملفات التحميل
```
