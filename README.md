# Creativo 📦

**منصة للمنتجات الرقمية تعمل بنظام الاشتراكات الشهرية والسنوية**
A digital products platform with monthly / yearly subscriptions.

## ✨ المزايا / Features

- 🛍️ **كتالوج 17 منتجاً رقمياً جاهزاً** موزعة على **10 أقسام**:
  قوالب · كورسات · إي-بوكس · صوتيات · موسيقى · فيديوهات · صور · خطوط · عناصر تصميم · ملفات
- 🏷️ **فلترة فورية** للمنتجات حسب القسم من الصفحة الرئيسية
- 💳 **اشتراكات شهرية وسنوية** — تفعيل فوري، تجديد (يُضاف على المدة المتبقية)، وإلغاء يُبقي الصلاحية حتى نهاية الفترة المدفوعة
- 🔐 **حسابات مستخدمين** — تسجيل/دخول بكلمات مرور مشفّرة (bcrypt) وجلسات HttpOnly لمدة 30 يوماً
- 📥 **منطقة تحميل** — الملفات تُحمّل فقط مع اشتراك فعّال، مع عدّاد تحميلات
- 🌍 **ثنائية اللغة** — واجهة عربية (RTL) وإنجليزية (LTR) مع زر تبديل فوري
- 📊 **لوحة إدارية كاملة** — إحصائيات (إيرادات، اشتراكات نشطة، مستخدمون، تحميلات)، رسم بياني للإيرادات (6 أشهر)، إدارة المنتجات (إضافة/تعديل/حذف + رفع ملف أو لصق نص)، إدارة المستخدمين، وتحكم في أسعار الخطط
- 💰 **دفع تجريبي (Mock)** — نموذج بطاقة محاكى، لا يتم خصم أي مبلغ حقيقي

## 🚀 التشغيل / Quick start

```bash
npm install
npm run dev        # http://localhost:3000
```

قاعدة البيانات (SQLite) تُنشأ وتُزرع ببيانات تجريبية تلقائياً في `data/creativo.db` عند أول تشغيل.

## 👤 حسابات تجريبية / Demo accounts

| الدور | البريد | كلمة المرور |
|---|---|---|
| 👤 مستخدم (باسم اشتراك سنوي فعّال) | `demo@user.com` | `Demo@123` |
| 👑 مسؤول | `admin@demo.com` | `Admin@123` |

- **المستخدم**: جرّب `/dashboard` — راقب اشتراكك، حمّل المنتجات، جدّد، أو ألغِ.
- **المسؤول**: ستنتقل تلقائياً إلى `/admin` — الإحصائيات، المنتجات، المستخدمون، الإعدادات.
- يمكنك إنشاء حساب جديد من `/register` وتجربة الدفع التجريبي في `/checkout`.

## ⚙️ التقنيات / Tech stack

- **Next.js 14** (App Router) + **TypeScript**
- **SQLite** عبر وحدة `node:sqlite` المدمجة في Node 22 (بدون أي اعتماديات أصلية)
- **Tailwind CSS 3** + خطوط Cairo (عربي) و Inter (إنجليزي)
- **bcryptjs** لتشفير كلمات المرور، جلسات بملفات تعريف ارتباط HttpOnly

## 🧠 منطق الاشتراكات / Subscription logic

1. **إنشاء اشتراك**: إذا كان للمستخدم اشتراك غير منتهٍ، تُحتسب البداية من تاريخ انتهائه (تراكم المدة)، وإلا من تاريخ اليوم.
2. **المدة**: شهر واحد أو سنة كاملة حسب الخطة (الأسعار من `settings`).
3. **الحالة**: `active` (نشط) · `cancelled` (ملغى — مع بقاء الصلاحية) · `expired` (منتهٍ). تُحسب الحالة من التاريخ لحظياً فلا حاجة لمهام مجدولة.
4. **التحميل**: متاح فقط مع اشتراك غير منتهى، ويُسجَّل في جدول `downloads` للإحصائيات.

> ⚠️ هذه منصة **تجريبية**: الدفع محاكى بالكامل ولا يتصل بأي بوابة دفع حقيقية.
