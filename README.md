# صَدَى — لُغزُ الأجراس والمَوجة ✦

لعبة ألغاز **موسيقية مكانية** أصلية لكلّ الأعمار: ضَعْ أجراساً ملوّنة على الشبكة وأطلق
الموجة من الحَجَر؛ كلُّ جرسٍ يرنّ حين تصله الموجة، و**ترتيبُ الرنين هو اللحن**.
المطلوب أن يُطابق لحنُك اللحنَ المكتوب فوق اللوحة.

- **٢٤ مرحلة** في ٤ فصول: الرنين الأول، الظلال (الجدران)، البوّابات، المعزوفة.
- الجدران تصنع ظلالاً تؤخّر الموجة، والبوّابات تنقلها، والمشاعل تُضاء مع مرورها.
- لا يوجد «خسارة» إطلاقاً — تجريبٌ حرّ، وتراجعٌ غير محدود، وتلميحات.
- **استوديو** لبناء لوحتك الخاصة وعزفها.
- صوت مُصنَّع بالكامل عبر Web Audio (أجراس غير توافقية + صدى)، يعمل بالماوس واللمس ولوحة المفاتيح.
- عربية RTL، أسلوب بسيط أنيق، تقدّم ونجوم محفوظة في المتصفح.

## التشغيل

اللعبة صفحة ويب بلا اعتماديات. شغّل أي خادم ثابت من هذا المجلّد:

```bash
python3 -m http.server 8000 --directory sada
# ثم افتح:  http://localhost:8000/
```

## التحقق الآلي

- `npm run verify:sada` — يبني خريطة الموجة لكل مرحلة، يعدّ **كل** الحلول الممكنة،
  ويتحقّق أن كل مرحلة قابلة للحلّ وأن حلّ الحلّال يمرّ بفحص اللعبة نفسه.
- `npm run test:sada` — اختبار لعب من طرف إلى طرف (jsdom): يفتح المراحل ويضع الأجراس
  بالأحداث الحقيقية ويعزف ويتحقّق من الفوز والنجوم والحفظ. يحتاج: `npm i -D jsdom`.
- `node sada/tools/shot.mjs` — يلتقط صوراً للوحة الحقيقية (يحتاج jsdom و `@napi-rs/canvas`).

الملفات المشتركة بين المتصفح وNode (`js/sim.js`) هي نفسها التي يفحصها المُتحقِّق،
فلا يوجد منطقٌ مزدوج.

## القوانين باختصار

| العنصر | السلوك |
|---|---|
| الحَجَر | يُطلق موجة تنتشر خليةً كلَّ خطوة |
| الجرس | يرنّ لحظة وصول الموجة (الأجراس لا تحجبها) |
| الجدار | يحجب الموجة؛ ما خلفه يتأخّر أو لا يصل |
| البوّابة | تنقل الموجة إلى أختها |
| المشعل | يُضاء مع الموجة (زينة) |
| النغمات في عمودٍ واحد | ترنّ معاً (اتفاق) |
