# رنين البلّور ✦

> لعبة ألغاز فريدة: تضرب الأرض لا البلورة. موجةٌ على شكل صليب تدفع أول جوهرة على كل محور، فتنزلق ككرة بلياردو حتى جدار أو بلورة أخرى — والزخم ينتقل عند الاصطدام كمهد نيوتن.

![الغرف](https://img.shields.io/badge/الغرف-٢٤-5eead4) ![الفصول](https://img.shields.io/badge/الفصول-٦-a78bfa) ![PWA](https://img.shields.io/badge/PWA-قابلة_للتثبيت-04060f)

## الآلية

1. **ضربة الصليب** — اضغط بلاطة فارغة. أربعة أشعة (أو ثمانية على المُضخّم) تطلق أول بلورة على كل شعاع.
2. **انزلاق جليدي** — البلورة تطير حتى جدار أو بلورة. ما لامس جداراً لا يرجع عنه.
3. **بلياردو نيوتن** — الاصطدام ينقل الزخم: الأولى تتوقف والثانية تنطلق. المتلاصقات تمرّر الطاقة للأخيرة.
4. **قفل اللون** — القاعدة تقبل لونها فقط ثم تُقفل فتصير جداراً.
5. **الصدى** — بلورة الهالة إذا تحركت تُطلق موجة جديدة من موضع توقفها.

٢٤ غرفة في ستة كهوف: النداء، المهد، الطيف، الصدى، المتاهة، السيمفونية.

## التقنيات

React 19 · TypeScript · Vite · Tailwind CSS 4 · Framer Motion · Web Audio API

الصوت يُصنَّع داخل المتصفح (زجاج الكهف + طنين) — بلا ملفات صوتية.

## التشغيل
