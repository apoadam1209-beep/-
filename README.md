# الآيس كريم الهارب

لعبة ويب: كرة الآيس كريم هربت من المخروط. اجرِ في الشارع، مدّ لسانك، والحسها قبل ما تذوب — أو قبل ما يسبقك الكلب والولد والميكروباص.

## اللعب

- اسحب / حرّك المخروط
- اضغط (أو مسافة) لمدّ اللسان
- ١٢ شارعاً + وضع لانهائي
- نكهات تغيّر الفيزياء: فانيليا، شوكولاتة، فستق، مانجو، فراولة (تنقسم)

## تشغيل

```bash
npm install
npm run dev
```

بناء نسخة صفحة واحدة:

```bash
npm run build
node server.mjs
```
