# ضوء رمضان

اسحب الفانوس لأي اتجاه وطابق ثلاثة نفس اللون جنب الإطار الذهبي. العتمة تروح والنور يفضل.

- ٣٠ ليلة رمضان × ١٠ حارات = ٣٠٠ دور
- فوانيس بألوان صريحة: أحمر، أخضر، ذهبي، أزرق، بنفسج
- المطلوب واضح: المربعات اللي ليها إطار ذهبي
- ثلاث نجوم لكل حارة

```bash
npm install
npm run build
node server.mjs
```
