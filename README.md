# رنين البلّور ✦

> لعبة ألغاز فريدة: تضرب الأرض لا البلورة. موجةٌ على شكل صليب تدفع أول جوهرة على كل محور، فتنزلق ككرة بلياردو حتى جدار أو بلورة أخرى — والزخم ينتقل عند الاصطدام كمهد نيوتن.

![الغرف](https://img.shields.io/badge/الغرف-٢٠٠-5eead4) ![الكهوف](https://img.shields.io/badge/الكهوف-١٠-a78bfa)

## الآلية

1. **ضربة الصليب** — بلاطة فارغة. أربعة أشعة (أو ثمانية على المُضخّم).
2. **انزلاق جليدي** — حتى جدار أو بلورة. ما لامس جداراً لا يرجع.
3. **بلياردو نيوتن** — الاصطدام ينقل الزخم.
4. **قفل اللون** — القاعدة تقبل لونها فقط ثم تُقفل.
5. **الصدى** — بلورة الهالة تُطلق موجة من موضع توقفها.

٢٠٠ غرفة في عشرة كهوف، صوت كهف حيّ (تقطير وريح وزجاج)، ومشهد واقعي من حجر وبلورات.

## التشغيل

```bash
npm install
npm run dev
npm run build
```
